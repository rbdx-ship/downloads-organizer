# Historical reference

`downloads_organizer_app_step10_part2_repaired.py` is the preserved single-file
Tkinter application from Step 10 of the original learning project.

`test_policy_matches_original` in `tests/test_organizer.py` imports it to compare
the classification-policy fingerprint and model with the modular application.
Keep the reference script unchanged so that it remains a useful baseline.

This folder is not part of the current application. Start the supported PySide6
interface with `python downloads_organizer.py` from the repository root.
